# Getting Started

## Installation

### Recommended: one-shot setup

Installs the package and its required peer dependencies, then writes the Tailwind v4 theme CSS and a theme setup helper:

```bash
npx @arkite-ui/core init
```

### Manual install

```bash
pnpm add @arkite-ui/core
```

### Peer Dependencies

```bash
pnpm add react react-dom tailwindcss zustand lucide-react
```

Optional (for animated components):

```bash
pnpm add framer-motion
```

## Setup

### 1. Import CSS

In your app's entry point (e.g. `main.tsx` or `layout.tsx`):

```tsx
import '@arkite-ui/core/styles.css'
```

This includes all theme tokens, base styles, and utility classes.

### 2. Tailwind CSS v4

Arkite UI uses **Tailwind CSS v4**. Your project's CSS file should import Tailwind:

```css
@import "tailwindcss";
@import "@arkite-ui/core/styles.css";
```

### 3. Use Components

```tsx
import { Button, Input, Badge, DataTable } from '@arkite-ui/core'

function App() {
  return (
    <Button variant="primary" onClick={() => alert('Hello!')}>
      Click me
    </Button>
  )
}
```

## TooltipProvider

If you use any Tooltip components, wrap your app with `TooltipProvider`:

```tsx
import { TooltipProvider } from '@arkite-ui/core'

function App() {
  return (
    <TooltipProvider>
      {/* your app */}
    </TooltipProvider>
  )
}
```

## Local Development (npm link)

For consuming projects during local development:

```bash
# In arkite-ui directory
pnpm link

# In your project
pnpm link @arkite-ui/core
```
